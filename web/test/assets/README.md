# Browser-suite test documents

Two real SEC filings, kept here rather than in `tests/fixtures/` because they are
**not** hand-verified fixtures and must not be mistaken for one. The library's
fixtures have expected values a person read off the filing; these have expected
*behaviour*.

| file | filing | why it is here |
| --- | --- | --- |
| `alk_1994_sgml_sct.txt` | Alaska Air Group DEF 14A, 1994-03-31 | The only committed document that selects the **SGML** backend. Every `.txt` fixture in `tests/fixtures/` contains `<TABLE>` markup but loses to an ASCII candidate on score, so without this the SGML path is never exercised in the browser. |
| `abcp_1997_review_flags.txt` | AmBase / ABCP DEF 14A, 1997-02-27 | Raises real review flags — `ambiguous_selection` and `missing_required_columns` — alongside the provenance flag `sgml_source`. Needed to show the two kinds of flag stay separate on a result that genuinely has both. |

Both came from the local corpus at `../data/`. They are asserted against
`test/expected/cases.json`, which is generated by running the same bridge module
under host CPython — so what they pin is that the browser agrees with CPython,
not that the extraction is correct.

Public SEC filing content. The SEC permits reuse of filings; they are submitted
by private parties, so "public domain" would be the wrong description.
